# CrowdDev — Post-V1 Backlog

Ideas in this file are deliberately deferred. Listing an item here does not authorize implementing it before V1 ships.

To promote an item into V1, follow the scope-change policy in `CROWDDEV_V1_SPEC.md` and identify an existing feature to defer in exchange.

## Deferred ideas

- GitHub/GitLab repository linking, webhooks, issues, pull requests, and release synchronization.
- In-platform tasks, project boards, milestones, code review, and contributor workflow.
- Project-level governance policies and community-managed maintainer permissions.
- Formal votes for technical decisions or changes to project governance.
- Multiple governance presets / configurable voting rules.
- Comments, threaded discussions, chat, and direct messages.
- Notifications beyond account verification and essential transactional flows.
- Image/file uploads and collaborative design tools; V1 accepts external reference URLs.
- Advanced user profiles, skill tags, public portfolios, and contribution history.
- AI-assisted idea refinement or moderation.
- Analytics dashboard, gamification, badges, and leaderboards.
- Native mobile application.
- Custom Go API/service for a later backend-career-focused milestone.
